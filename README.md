## Featured projects

### [RISC-V Emulator](https://github.com/zaparsenal/riscv-emulator)

A correctness-first RV32IM emulator and performance-analysis environment written in C++20. It supports static ELF32 loading, Linux-style output and termination syscalls, an interactive debugger, configurable cache and branch-prediction models, reproducible benchmarks, and pinned architectural conformance smoke tests.

`C++20` `CMake` `RISC-V` `ELF` `GoogleTest` `GitHub Actions`

### [EmberDB](https://github.com/zaparsenal/emberdb)

A local columnar analytics engine for football event data. It normalizes StatsBomb, Metrica, and Wyscout data into a provider-independent typed schema, with versioned columnar persistence, typed queries and aggregations, canonical identity catalogs, and reviewable reconciliation workflows.

`C++20` `CMake` `Columnar Storage` `Data Ingestion` `GoogleTest`

### [Owala Water Tracker](https://github.com/zaparsenal/Owala-tracker)

An NFC-enabled personal water tracker. Scanning a tag on the bottle triggers Apple Shortcuts to log water, while a Next.js dashboard provides daily progress, history, unit conversion, and protected corrections.

`TypeScript` `Next.js` `Prisma` `PostgreSQL` `Tailwind CSS` `Vercel`
