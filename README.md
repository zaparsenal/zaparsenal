# Zayd Patel

I build software for systems and data problems. Recent work spans a RISC-V emulator, a football event analytics engine, and small tools I use myself.

## Projects

- **[RISC-V Emulator](https://github.com/zaparsenal/riscv-emulator)** — Run and debug RV32IM programs in C++; includes cache and branch-prediction models.
- **[EmberDB](https://github.com/zaparsenal/emberdb)** — Import football event data from multiple providers and query it through a local columnar engine.
- **[FieldGuide Process Insights](https://github.com/zaparsenal/test-agent)** — Explore synthetic industrial process scenarios through data checks, ranked findings, and visual answers.
- **[Owala Water Tracker](https://github.com/zaparsenal/Owala-tracker)** — Log water with an NFC sticker and iPhone Shortcut, then track progress on a web dashboard.

I work mainly with C++, TypeScript, and SQL, using tools such as CMake, Next.js, Prisma, and PostgreSQL.
